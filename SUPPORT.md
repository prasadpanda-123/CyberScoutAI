# Support & Community Guide

Thank you for using CyberScout AI! Here is how you can get help, report issues, and engage with the community.

---

## 🔍 How to Get Help

### 1. Documentation & Guides
Before asking a question, please check if your answer is covered in our documentation:
- [README.md](README.md) — Setup & Quickstart Guide
- [docs/design/PHASE11_DASHBOARD.md](docs/design/PHASE11_DASHBOARD.md) — Web Dashboard Architecture
- [docs/api/DASHBOARD_API.md](docs/api/DASHBOARD_API.md) — REST API Reference
- [ROADMAP.md](ROADMAP.md) — Project Roadmap

### 2. Common Troubleshooting Commands
If you encounter runtime issues, run built-in diagnostics:
```bash
# Run system health check
python main.py --health

# Verify configuration validity
python main.py --config-check

# Verify database connection
python main.py --db-check
```

## 🐛 Reporting Bugs

If you find a bug:
1. Search existing [GitHub Issues](https://github.com/CyberScoutAI/cyberscout-ai/issues) to ensure it hasn't been reported yet.
2. If new, open a issue using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
3. Include your Python version, OS platform, and full stack trace logs.
