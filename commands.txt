===========================================================================
CyberScout AI CLI Reference
===========================================================================

VERSION

python main.py --version
    Show application version

===========================================================================
SYSTEM
===========================================================================

python main.py
    Start default application bootstrap and graceful shutdown

python main.py --health
    Run full system health check suite.

python main.py --config-check
    Validate application configuration settings.

python main.py --validate-rss
    Execute live RSS feed fetching and XML parser validation.

python main.py --rss-report
    Display RSS feed parser diagnostics and error tracking report.

python main.py --repair-config
    Automatically repair source collector recommendations in sources.yaml.

python main.py --db-check
    Verify PostgreSQL database connectivity and schema integrity.

python main.py --run-scheduler
    Run daily report scheduler daemon loop in background execution mode.

python main.py --send-report
    Immediately generate and send today's intelligence report, updating scheduler state.

python main.py --smtp-check
    Execute end-to-end SMTP configuration, DNS resolution, TCP connection, and authentication checks.

python main.py --quality-report
    Display Quality Intelligence Engine acceptance and rejection statistics.

python main.py --quality-check
    Run Quality Intelligence validation against current database opportunities.

python main.py --quality-stats
    Display aggregated quality metrics (confidence distribution, keyword frequency, etc.).

python main.py --quality-test
    Run a test evaluation of a sample opportunity through the Quality Engine.

python main.py --rejected
    List recently rejected opportunities with rejection reasons.

python main.py --provider-report
    Display provider reliability rankings and star ratings.

python main.py --freshness-report
    Display opportunity freshness and decay statistics.

python main.py --trend-report
    Display top growing skills, hiring companies, and trending categories.

python main.py --history-report
    Display historical opportunity lifecycle state transitions.

python main.py --validate-links
    Execute URL link validation diagnostics against active database opportunities.

python main.py --verify-content
    Execute page content verification checks.

python main.py --production-report
    Display comprehensive Production Intelligence master telemetry report.

===========================================================================
AUTOMATION
===========================================================================

python main.py --run-once
    Execute one complete scan & pipeline iteration.

python main.py --daemon
    Run automation engine daemon scheduler loops continuously.

python main.py --dry-run
    Run full collection and ranking cycle but bypass DB writes and email dispatching.

python main.py --scheduler-status
    Inspect scheduler state, timezone, next scheduled run, and email status.

python main.py --metrics
    Display performance timings for the last completed run.

===========================================================================
EMAIL
===========================================================================

python main.py --email-test
    Sends a test notification email digest.

DASHBOARD

CONFIGURATION
===========================================================================

python main.py --validate-config

python main.py --config-report
    Generate master configuration audit summary report.
